# Текущие задачи – чек-лист реализации

- [ ] Модуль common/file_reader — открытие/закрытие файлов и построчное чтение с помощью `getline`.
- [ ] Модуль common/string_utils — вспомогательные функции: проверка пустой строки, замена символов, кодирование управляющих символов для `-v`, поиск подстрок для `grep -o`.
- [ ] Модуль common/error_handler — вывод ошибок с поддержкой подавления (`grep -s`).
- [ ] Модуль cat/parser — разбор аргументов командной строки для `s21_cat` (все флаги).
- [ ] Модуль cat/processor — обработка строк: сжатие пустых строк, нумерация, замена табуляции, маркеры конца строки, отображение непечатных символов.
- [ ] Модуль cat/s21_cat — главный цикл: для каждого файла вызвать процессор и вывести результат.
- [ ] Модуль grep/parser — разбор аргументов `s21_grep`, включая `-e`, `-f` и комбинации флагов.
- [ ] Модуль grep/matcher — компиляция регулярных выражений (POSIX regex) и поиск совпадений с учётом `-i`, `-v`, `-o`.
- [ ] Модуль grep/output — форматирование вывода для `-c`, `-l`, `-n`, `-h`, `-o` и их сочетаний.
- [ ] Модуль grep/s21_grep — главный цикл: разбор флагов, обход файлов, сбор совпадений, вызов модуля вывода.
- [ ] Makefile (src/cat/Makefile) — сборка `s21_cat` с линковкой `libcommon.a`.
- [ ] Makefile (src/grep/Makefile) — сборка `s21_grep` с линковкой `libcommon.a` и `-lregex`.
- [ ] Интеграционные тесты для cat — скрипты сравнения `s21_cat` с `busybox cat` для всех флагов.
- [ ] Интеграционные тесты для grep — скрипты сравнения `s21_grep` с `busybox grep` для базовых и бонусных флагов.
- [ ] Документация — краткий `README.md` с инструкциями по сборке и тестированию.
