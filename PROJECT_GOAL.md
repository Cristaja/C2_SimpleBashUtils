# Цель проекта

Разработать две консольные утилиты для обработки текста на языке C стандарта C11:
- `s21_cat` – аналог утилиты `cat` (объединение и вывод файлов).
- `s21_grep` – аналог утилиты `grep` (поиск строк по регулярному выражению).

Утилиты должны поддерживать основные флаги, описанные в задании, корректно обрабатывать ошибки, быть собраны через `Makefile` и протестированы путём сравнения с поведением оригинальных утилит `cat` и `grep` (версии busybox Alpine 3.20).

Проект закрепляет навыки структурного программирования, работы с файловым вводом-выводом, парсинга аргументов командной строки, регулярных выражений (POSIX regex) и модульной организации кода.
